# Implantação Atlas — pasta nossa

Esta pasta **não é o produto oficial**. É o material da Scope para
**aprender, divulgar, vender, implantar e manter** o CRM (Deskcomm,
revendido como Atlas CRM).

Não commitar no GitHub oficial. Não copiar para a VPS no lugar do clone
oficial. Não colar senha, token `dsk_…`, chave de IA ou VAPID aqui.
